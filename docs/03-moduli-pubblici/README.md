# Moduli pubblici

> **A chi serve:** chi si iscrive, si candida o arriva a un evento; agli organizzatori, per sapere cosa vede chi riceve un link.

> **Come è stata scritta.** Questa guida è stata scritta interamente con l'ausilio di un agente di intelligenza artificiale, Claude Code di Anthropic con il modello Claude Opus 5.5, in base alle indicazioni dello sviluppatore e all'analisi diretta del codice. Il contenuto è verificato sul funzionamento reale del programma, ma finché non sarà revisionato da una persona alcuni passaggi potrebbero mancare e le motivazioni di alcune scelte potrebbero non essere spiegate con precisione. Le pagine già revisionate lo indicano in apertura con la riga «Pagina revisionata» e la data.

Sono le pagine che si aprono **senza accesso**, da un link ricevuto per email o diffuso dagli organizzatori, oppure inquadrando il codice QR di un badge. Sono pensate per il telefono e funzionano in qualsiasi browser.

Il **check-in all'ingresso** non è una pagina pubblica: il partecipante mostra il proprio QR alla segreteria ([Badge e messaggi](06-badge-e-messaggi.md#il-qr-per-il-check-in)), e la scheda si apre solo a un operatore collegato al pannello e abilitato per l'evento ([Presenze live](../01-pannello/02-gestione-operativa/01-eventi/06-presenze-live.md#registrare-ingressi-e-uscite)).

I form di preregistrazione si possono compilare anche dall'[app dei soci](../02-app-soci/03-moduli-dall-app.md): sono gli stessi form, con gli stessi campi e le stesse regole.

**Nei testi scritti dagli organizzatori** (per esempio la dicitura dell'autocertificazione di una graduatoria o del documento aggiuntivo di un corso) gli indirizzi web diventano da soli un link **Apri il link (dominio)** con accanto il pulsante **Copia indirizzo**. Non serve più chiedere di copiare l'indirizzo nella barra del browser.

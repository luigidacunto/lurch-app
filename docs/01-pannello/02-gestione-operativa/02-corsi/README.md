# Corsi

> **A chi serve:** operatori e amministratori del pannello.

I corsi sono la parte didattica e amministrativa di un [evento](../01-eventi/README.md): iscritti, moduli di preregistrazione, quote, comunicazioni ai corsisti. Ogni corso appartiene a un evento, che ne cura la logistica (sede, pasti, pernottamenti, badge, presenze).

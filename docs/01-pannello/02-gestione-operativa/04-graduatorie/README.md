# Graduatorie

> **A chi serve:** operatori e amministratori del pannello.

Una graduatoria serve quando i posti di un corso sono limitati e i partecipanti vanno **selezionati** tra chi si candida. Il pannello crea un **link pubblico** a cui i volontari si candidano con il codice fiscale ([Candidatura a graduatoria](../../../03-moduli-pubblici/03-candidatura-graduatoria.md)); alla chiusura il pannello calcola punteggi e classifica secondo i criteri scelti, e indica chi è ammesso.

La graduatoria è indipendente dal corso: può essere collegata a un corso (anche creandola dal modulo del corso, vedi [Creare e modificare un corso](../02-corsi/02-creare-e-modificare.md)), ma il collegamento è solo informativo.

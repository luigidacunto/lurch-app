# Guida di LURCH

Guida completa all'uso di LURCH, divisa per chi la legge. Le sezioni Pannello di gestione, App dei soci e Moduli pubblici si leggono anche nel pannello, alla voce di menu **Guida**; Installazione solo qui.

> 🚧 La guida è in fase di scrittura: le pagine segnate «In preparazione» arriveranno nelle prossime versioni.

## [Installazione](00-installazione/README.md)

Per chi installa e gestisce il server o vuole contribuire allo sviluppo: requisiti e sviluppo locale, deploy, backup e ripristino, aggiornamenti.

## [Pannello di gestione](01-pannello/README.md)

Per operatori e amministratori: primi passi, gestione operativa (eventi, corsi, esami, graduatorie, qualifiche), archivi, impostazioni, strumenti. Stesso ordine del menu del pannello.

## [App dei soci](02-app-soci/README.md)

Per i volontari che usano l'app `/app`: accesso con codice, eventi, moduli, messaggi, esami.

## [Moduli pubblici](03-moduli-pubblici/README.md)

Per chi si iscrive, si candida o arriva a un evento: preregistrazioni, candidature, verifica email, badge e check-in, privacy.

# Modello TCRI

> **A chi serve:** direttore, commissione e docenti dei corsi TCRI.

Il modello TCRI stabilisce come si valuta un esame dei corsi TCRI: quali prove ci sono, quali schede compilano docenti e commissione, con quali pesi si calcola il punteggio finale. Le pagine di questo capitolo valgono solo per gli esami che usano questo modello; il resto della guida vale per ogni esame.
